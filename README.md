# 86 News

Україномовний Telegram-бот для шкільних новин. Команда /news показує три останні публікації, /subscribe вмикає сповіщення, /unsubscribe вимикає їх.

## Запуск на Railway

1. Створіть проєкт у Railway, виберіть Deploy from GitHub repo та цей репозиторій. Dockerfile у корені містить команду запуску.
2. У Variables додайте BOT_TOKEN із BotFather.
3. Створіть Volume, підключіть його до сервісу бота за шляхом /data. Тут зберігатиметься база SQLite.
4. Закрийте локальну копію бота й натисніть Deploy. Перевірте запуск командою /start у Telegram.
5. Надішліть боту /id. Додайте отримане число як ADMIN_ID у Variables і застосуйте зміни. Для публікації надішліть /post і текст оголошення одним повідомленням.

Для кількох редакторів вкажіть усі їхні ID в одній змінній `ADMIN_ID` через кому, наприклад `123456789,987654321`. Кожен редактор має доступ до /post та /stats.

## Запуск у Windows

Відкрийте Start.cmd у папці windows. [Докладна інструкція](windows/README.md).
## Скарги та пропозиції

У приватному чаті натисніть «💬 Скарги та пропозиції» або введіть /feedback. Оберіть анонімну скаргу, скаргу з підписом або пропозицію з підписом. Наступне текстове повідомлення надійде редакторам. До надсилання можна натиснути «Скасувати».

Для анонімної скарги бот створює нове повідомлення лише з текстом. Для підписаного звернення додає Telegram ID автора. Кожен редактор з ADMIN_ID має спочатку відкрити бота в Telegram і надіслати /start, щоб отримувати звернення.
