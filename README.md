# 86 News

Україномовний Telegram-бот для шкільних новин. Команда /news показує три останні публікації, /subscribe вмикає сповіщення, /unsubscribe вимикає їх.

## Запуск на Railway

1. Створіть проєкт у Railway, виберіть Deploy from GitHub repo та цей репозиторій. Dockerfile у корені містить команду запуску.
2. У Variables додайте BOT_TOKEN із BotFather.
3. Створіть Volume, підключіть його до сервісу бота за шляхом /data. Тут зберігатиметься база SQLite.
4. Закрийте локальну копію бота й натисніть Deploy. Перевірте запуск командою /start у Telegram.
5. Надішліть боту /id. Додайте отримане число як ADMIN_ID у Variables і застосуйте зміни. Для публікації надішліть /post і текст оголошення одним повідомленням.

Для кількох редакторів вкажіть усі їхні ID в одній змінній `ADMIN_ID` через кому, наприклад `123456789,987654321`. Кожен редактор має доступ до /post та /stats.

## Запуск у Windows

Відкрийте Start.cmd у папці windows. [Докладна інструкція](windows/README.md).
## Скарги та пропозиції

У приватному чаті натисніть «💬 Скарги та пропозиції» або введіть /feedback. Оберіть анонімну скаргу, скаргу з підписом або пропозицію з підписом. Наступне текстове повідомлення надійде редакторам. До надсилання можна натиснути «Скасувати».

Для анонімної скарги бот створює нове повідомлення лише з текстом. Для підписаного звернення додає Telegram ID автора. Кожен редактор з ADMIN_ID має спочатку відкрити бота в Telegram і надіслати /start, щоб отримувати звернення.
## Міні застосунок редакції у Railway

У сервісі бота відкрийте Settings → Networking → Public Networking → Generate Domain. Для стандартної конфігурації виберіть порт 8080. Якщо в Variables задано інший PORT, вкажіть цей самий порт. Застосуйте зміни. Бот використовує HTTPS-адресу з RAILWAY_PUBLIC_DOMAIN. Для власного домену можна вказати повну HTTPS-адресу у MINI_APP_URL.

Редактор надсилає /admin і натискає «Відкрити редакцію». Тут можна написати новину, прикріпити одне фото, переглянути допис і підтвердити публікацію. Текст із фото — до 1000 знаків, без фото — до 4000. Новина зберігається у стрічці, а підписники отримують її через звичайну чергу розсилки. Права перевіряються за підписом Telegram та списком ADMIN_ID на сервері.
## Опитування та статус звернення

У вкладці «Опитування» редактор вводить запитання та 2–10 варіантів, кожен з нового рядка. Після публікації бот розсилає опитування підписникам. Кнопка «Опитування» або /polls показує учням останні п’ять опитувань. Кожен учасник може змінити свій голос. У редакції відображаються сукупні результати з усіх чатів.

Для нового звернення бот видає приватний код. Учень натискає «Статус звернення» або /status і вводить код, щоб переглянути статус та відповідь. Код варто зберігати приватно. Редактори змінюють статус та пишуть відповідь у вкладці «Звернення». Для анонімної скарги запис звернення зберігає текст без ID автора.
