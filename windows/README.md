# 86 News

Україномовний Telegram-бот для шкільних новин. Читачі можуть переглядати три останні оголошення й підписуватися на нові. Редактор публікує новини в особистому чаті з ботом.

## Перший запуск

У Windows із встановленим Python відкрийте `Start.cmd` подвійним клацанням. Скопіюйте токен із BotFather, натисніть «Вставити токен», за бажанням введіть свій Telegram ID та натисніть «Запустити». Тримайте вікно відкритим, доки бот має працювати. Якщо ID ще невідомий, надішліть боту /id у Telegram, закрийте вікно та повторіть запуск зі своїм ID.

### Запуск через термінал

1. Відкрийте [@BotFather](https://t.me/BotFather) у Telegram, надішліть `/newbot`, вкажіть назву **86 News** і виберіть вільне ім’я користувача із закінченням `bot`. Збережіть виданий токен як пароль.
2. Розпакуйте архів. На комп’ютері з Python 3.9 або новішим відкрийте термінал у папці з файлом `bot.py`. У Windows виконайте `py bot.py`, у Linux чи macOS — `python3 bot.py`. Додаткові бібліотеки встановлювати не потрібно.
3. Введіть токен у терміналі. Символи під час введення приховані. Якщо знаєте свій числовий Telegram ID, введіть його як ID редактора. Якщо ні, натисніть Enter, відкрийте бота за посиланням із термінала та надішліть `/id`. Зупиніть програму клавішами Ctrl+C, повторіть запуск і введіть отриманий ID.
4. Надішліть боту `/start`. Для публікації введіть `/post`, пробіл і текст новини одним повідомленням. Після надсилання оголошення одразу з’явиться у стрічці й потрапить до черги розсилки.

## Робота бота

Для постійної роботи залишайте програму запущеною на комп’ютері або сервері з інтернетом. Запускайте одну копію на токен. Для автоматичного запуску можна передати токен та ID редактора через змінні середовища `BOT_TOKEN` та `ADMIN_ID`.

Публікації, підписки та черга розсилки зберігаються у файлі SQLite поруч із програмою. Для перенесення зупиніть бота й скопіюйте цей файл разом із програмою.
